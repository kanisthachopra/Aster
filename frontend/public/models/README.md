# Local motion model

`pose_landmarker_full.task`: Google MediaPipe Pose Landmarker Full, float16, version **1**. Replaces the initial Lite model after local comparisons showed better tracking on difficult exercise footage.

- Download: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/1/pose_landmarker_full.task
- SHA-256: `5134a3aad27a58b93da0088d431f366da362b44e3ccfbe3462b3827a839011b1`
- Model card / Apache-2.0 license: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf (page 2).
- License text: `../mediapipe/LICENSE.txt`.
- Runtime: `@mediapipe/tasks-vision` **0.10.32**, pinned in package-lock.json. `../mediapipe/vision_bundle.js` is the unmodified package `vision_bundle.cjs`, renamed so a classic worker can load it. Both SIMD/non-SIMD WASM variants and their loaders are copied unchanged from that package. The worker provides the CommonJS `exports` object. No CDN, cloud inference, credentials or private-video upload is used.

The JavaScript runtime and model run in a dedicated worker. Cancelling terminates it. Each analysis samples up to four frames per second (maximum 360), accepts 2–120 second clips, and rejects files above 150 MB. Angles use image aspect correction; estimated depth is not treated as a physical measurement. Visibility ≥0.55 plus finite-coordinate/in-frame checks gates each three-joint chain independently. Missing head or ankle points do not invalidate an elbow. Two-person detections are discarded.

The most consistently measurable side is selected for a set. Missing angles remain null, never zero or extrapolated. Short tracking gaps up to 0.8 seconds may be bridged when counting; longer gaps reset a cycle. Eight compatible samples and a complete 28°-minimum robust projected excursion (either extended–bent–extended or bent–extended–bent) qualify as a visible cycle. For pull-ups the wrist must remain approximately anchored while the shoulder rises; reaching for the bar is not counted. Camera-position rules distinguish compatible, uncertain and clearly incompatible positions. They are exploratory capture/movement rules, not validated exercise classifiers or form limits.

Reports distinguish useful movement review (`usable`), limited joint/position observations without a confirmed cycle (`partial`), and insufficient evidence. Partial reports can be saved without activity/energy credit. A long setup or cropped non-essential body part no longer discards a useful movement segment. Person-detection coverage and per-joint measurement coverage are reported separately. The middle 80% of measured angles reduces isolated-outlier influence; evidence links point to actual sampled frames. Capture notes identify observed missing joints and the longest tracking outage, while explicitly avoiding claims about what happened during untracked intervals.

Reports deliberately describe actual observations and uncertainty. No universal ideal angles, safety score or assertion that form is correct is generated. Single-view footage cannot establish pain, load suitability, injury, precise shoulder rotation or individual safe range. Form-coaching validation on representative exercise clips remains necessary.

## Optional reproducible model smoke test

Download Google's official public test image from https://storage.googleapis.com/mediapipe-assets/pose.jpg to `frontend/artifacts/analysis/pose.jpg`, then run `npm test -- analysis.spec.ts`. It is referenced in Google's [pose landmarker tests](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/tasks/python/test/vision/pose_landmarker_test.py). The image stays in ignored test artifacts and is not redistributed or shipped. The test checks real model inference, not exercise accuracy. Deterministic synthetic-joint tests separately check angle math, full cycles, gaps, incompatible orientation and stillness. The original generated colour-pattern video is a real-inference negative test.

## Real exercise smoke test (2026-10-08)

The optional `artifacts/real-exercise.mp4` fixture is a seven-second segment (source 81–88 seconds) of [Navy-seal-buds-training-push-ups.ogv](https://commons.wikimedia.org/wiki/File:Navy-seal-buds-training-push-ups.ogv), credited to the United States Navy SEALs. Commons identifies it as public-domain U.S. government work and applies the [Public Domain Mark](https://creativecommons.org/publicdomain/mark/1.0/). [Original media](https://upload.wikimedia.org/wikipedia/commons/e/e6/Navy-seal-buds-training-push-ups.ogv). Converted to H.264 and muted, with no synthesized movement. It stays in ignored artifacts and is not shipped. No endorsement is implied.

With the Full model and revised stable-side cycle rules, actual browser inference on this clip yielded 28 measurable frames of 28 sampled, one estimated visible cycle, and timestamp-linked observations. This is a real positive smoke test, not a representative accuracy evaluation. The tests also submit it to the other two stations and require no qualifying exercise completion. Cancellation and same-origin-only network behavior are tested separately. Independent synthetic tests cover aspect ratio, clipped/hidden joints, partial observations, stable-side selection, both cycle directions, brief/long gaps, stillness and isolated angle spikes.

Additional user-authorized videos were inspected and processed only locally for diagnostics. Private frames, filenames, landmarks and reports remain in ignored artifacts, never in shipped assets or tracked documentation. These diagnostics do not establish general accuracy. Extremely close crops can still remove the working joint chain entirely; the app must report that honestly. An official MoveNet Thunder fallback and image rotations were benchmarked locally and discarded because they did not restore reliable joint chains on the problematic crop. Their runtime and model are not shipped.
