# Production dependencies

No user-supplied resource is required to explore the first world slice.

Before validating real analysis, we need representative pull-up, push-up and squat clips with permission to use them, including clear views and difficult/occluded examples. Publicly visible media is not automatically licensed for redistribution. Use qualified human review to assess findings, and original or licensed demonstrations for the side-by-side reference library. Personal-reference photos remain an optional research question, not a prerequisite.

Before sending real media to an external model, select the provider and agree the exact processing destination and retention behavior. Configure credentials locally in ignored environment files, never in chat, frontend code or source control. No cloud provider has been integrated or purchased yet.

Final visual production requires a rigged protagonist, first-person suit/hand animations, per-exercise demonstrations, and a supported mapping from observed landmarks to avatar motion. Current geometry provides the playable composition and input test; it does not claim realistic anatomy or faithful reconstructed movement.

Final audio requires original score stems matching the approved sound brief and chosen robot/avatar voices. The current synthesis only tests silence, cue timing and mixing. The referenced film/game recordings are not included. A voice/performance audition and an audible score review remain necessary.

Deployment, private object storage, email recovery service, and spending choices remain open. Local preview operation does not require them. The installed Python version is 3.14; analysis-package compatibility must be checked before choosing the worker environment. PostgreSQL, Docker and ffmpeg were not found on PATH during the initial check.
